日期：2026-09-13。状态：新题目候选稿，用于内容审阅和后续开发；未完成专业审核、用户试测和测量性能验证，未接入 Demo。

依据：[已确认范围](02-MVP范围确认单.md)、[技术方案](03-技术方案.md)。专业资料及其读取状态见 [来源登记](06-首批知识内容与来源.md)。模型选型与接入后置，本项可以独立推进。

## 1. 这份稿件交付什么

提供 32 道重新组织措辞的候选题、选项、九个维度的初步覆盖、固定计分草案和结果页要求。32 是本稿的候选题数量，不是已经证明足够的题量；审核后可以删改、补题，再形成新的版本。

首版包含正式测评功能的决定不变。本文把“可以开发答题和计分流程”与“可以对个人给出有效体质判定”分别说明：前者已有可实施草案，后者仍需要题目、判定规则及适用条件的验证。

本稿不是 GB/T 46939—2025 原版问卷，也没有沿用原型的五题或固定平和质结果。已核对现行标准的名称、状态和九种类型，尚未取得并逐项核对最终标准全文。不能引用早期公共卫生记录表的分数门槛，直接给这套新题判定体质。[现行标准信息](https://openstd.samr.gov.cn/bzgk/std/newGbInfo?hcno=827D6D266BA52A2983F93638DA871028)

| S03，九类体质辨识的专业讨论 | 参考体质相关观察概念，主要用于痰湿、湿热、气郁维度 | 某个感受单独就能决定体质，或相关功法已在本产品验证 |
| S15，卫生健康部门体质科普 | 参考寒热、干燥及血瘀相关的常见表述 | 科普描述可以替代量表验证和临床评估 |
| S04，COSMIN 内容效度方法 | 审视题目是否相关、覆盖是否完整、用户能否理解 | 本问卷已经通过认证 |

题干、分组、选项编码和计算形式是本项目的设计提案。表中“概念依据”只指观察概念有出处，不表示出处验证了改写后的这道题。原料与健康建议不从体质分数自动推导。

不要求用户辨舌、摸脉或判断“气血是否不足”。体形、皮肤表现、情绪和体能可能受多种因素影响；每个维度的混杂因素都需要审核，不能将肥胖等同痰湿，将情绪困扰等同气郁，或将过敏等同于全部特禀特征。

## 3. 适用说明与答题体验

候选题先用于能够理解题意并自行回顾日常感受的成年人的可理解性试测。这是此问卷草稿的试测安排，不改变产品面向广泛人群的咨询定位。未成年人、代答、高龄、孕哺以及存在影响作答能力的情况，要分别核对适用依据；不直接宣称都适用或都不适用。当前没有任何人群获得此新问卷的测量验证结论。

开始页文案草稿：

> 回想过去一年里自己的日常感受，选择最接近的情况。不是只看今天，也不需要猜测病因。遇到记不清、不适用或不愿回答的问题，可以如实选择。当前问卷处于试测阶段，结果用于整理你的自我感受。

“过去一年”参考 S02 的回溯方式，仍需测试回忆负担与季节影响。近期急性不适、治疗变化或特殊生理状态可以补充说明；不让用户自行判断这些因素是否已经被排除。若当前出现需要及时处理的不适，提供退出问卷并求助的入口，不能等全部题目答完才提示。

流程为：说明与选择参与 → 答题 → 查看未答项 → 提交 → 查看参考结果 → 自愿保存。每屏显示少量题目，允许返回改答、退出和恢复本机草稿。预计时长先不写“准确 3 分钟”等承诺，试测后根据记录填写。

| 选项代码 | 用户看到的选项 | 计分用途 |
| --- | --- | --- |
| 0 | 从未或几乎没有 | 有效数值 |
| 1 | 偶尔，只有少数时候 | 有效数值 |
| 2 | 有时，间歇出现 | 有效数值 |
| 3 | 经常，多数时候 | 有效数值 |
| 4 | 几乎总是 | 有效数值 |
| UNSURE | 记不清／无法判断 | 不计作 0，不代填 |
| NOT_APPLICABLE | 这道题不适用 | 不计作 0，不代填 |
| DECLINED | 不愿回答 | 不计作 0，不强迫补答 |

所有计分题使用同一套频率选项，避免混合“发生频率”和“严重程度”。对于仅在某种接触或环境中出现的感受，无相应经历时可选“不适用”；它不等于证实没有过敏或其他问题。

## 6. 固定计分草案

首稿只计算描述性答题摘要，不提供“是／倾向某体质”的阈值。等权平均是便于复核的工程提案，尚不是通过测量验证的量表计分方法。

1. 校验问卷版本、计分版本、题目 ID 和答案代码。多余 ID、重复 ID、非整数或范围外值属于无效输入。
2. 完全未答的题目属于 `incomplete`；返回题目 ID，不补 0。
3. 选择三个非数值选项也算完成了该题的回答，但该维度不生成数值摘要；保留原因，状态为 `unscorable`。
4. 某一维度全部为有效数值时，`dimensionMean = sum(answer) / itemCount`，范围 0–4；计算保留原精度，内部显示可取两位小数。
5. 不计算总健康分、健康百分比、体质概率、排名或风险等级。首稿不以最高分指定主／兼夹体质。
6. 完成且可计算的记录仍为 `pilot_reference`。此版本的 `classification = null`、`agentEligible = false`；客户端不得自行改为已验证。

正式判定规则需另有版本，明确每类条件、交叉维度要求、兼夹处理、边界与不适用处理，再用相应资料和数据验证。取得参考量表的完整内容后，也不直接把其判定门槛套在本候选题上。

## 7. 结果页与保存

试测结果页显示“你的日常感受记录”，说明当前无法据此作正式个人体质判定；按原答案展示用户报告较频繁的具体感受，并保留全部答题查看入口。这里的“较频繁”只是用户选择了“经常／几乎总是”的文字汇总，不是临床阈值。没有这些回答就如实说明，不自动展示平和质。

九种体质科普可继续阅读，但不显示“你就是某体质”“你的某种体质概率为 80%”或据此自动推荐茶方。描述性维度分值仅用于内部审核与计算核对，不将未验证的雷达图作为个体健康报告展示。

记录包含：记录 ID、题目及计分版本、原答案、数值摘要或缺失原因、使用条件、提交时间、审核与验证状态。保存、草稿恢复、重新测评和删除遵循 [技术方案](03-技术方案.md)，仅在本机；旧五题固定结果不能迁移为新测评记录。

不使用体质摘要也能正常咨询。用户若主动在聊天里描述“最近容易累”，应按其直接描述澄清，不将其后台试测分数当诊断依据。

## 9. 从候选稿到正式使用

下一步先核对最终标准、相关原始研究与使用条件，逐题审查概念对应和措辞；重点处理 Q22 的双重表述、Q25 的低特异性、特禀维度覆盖不足及人群差异。必要时删除、拆题或补题，不为了保持 32 题而凑数。

再用小规模可理解性访谈观察用户怎样理解、回忆和选择答案，形成修订记录。这种小试不能证明信效度。后续测量验证的样本、重测安排、参照工具和判定规则由相应专业人员制定，不能用“几个人试用觉得准”代替。

当前审核人、审核日期、内容效度结果、测量验证结果均未填为通过。取得这些条件前，可以实现问卷容器、本机记录和描述性计分；不能把首版正式测评的最终验收标为完成。

本稿由助手整理，供产品与专业审阅；不要求用户先提供模型或自行编写题目。
