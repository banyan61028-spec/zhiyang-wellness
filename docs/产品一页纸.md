# 知养 · 产品一页纸

个人项目，作者 linden。给投资人开场和简历附件。状态与当前 `main` 试用版一致。日期：2026-10-07。

## 问题

人可以记下吃了什么，也看得到热量，下一顿吃什么仍要自己想。数字停在报表上，这一餐之后的决定没有被接住。

## 一句话产品

知养：记下吃了什么，看今天大约吃了多少，再从自己的食谱库里选下一餐。

## 目标用户

能自己安排三餐的普通成年人。外食和自己做饭都有，愿意花几十秒记一餐，想知道今天吃得是否大致合理、下一顿怎么补。

孕期、未成年、正在按医嘱控制饮食的人，以及出现催吐、绝食这类说法的人，可以留下记录。知养不会按热量缺口鼓励他们少吃。

## 和薄荷健康、Keep 的差异

薄荷健康、Keep 这一类产品，记完往往停在热量和营养素上。用户知道今天大约多少千卡，仍要自己决定下一顿。

知养把数字用在下一餐上：用一两句日常说法说出今天最要紧的一点，并从知养自己的食谱库里选出一道菜、说明理由。库里没有合适的，就直接说没有。展开见 [竞品分析](竞品分析.md)。

## 当前已上线闭环

1. 用邀请码打开试用。没有账号。
2. 在「记录」里拍照或写一句话，核对食物和分量（小、中、大，或直接改克数），再记下来。
3. 在「今日」看当天合计。只有自己确认过每日目标，才会和目标对比。
4. 下一餐只来自食谱库。不喜欢就换一道，也可以打开看原料和做法。

记录留在这台浏览器里。热量写成「约」，按食物表和克数计算。对不上的食物标成算不出来。

## 健康边界

知养提供饮食记录和下一餐参考，不提供诊断、用药建议或治疗膳食，也不是医疗器械。紧急描述只会提示联系当地急救（中国大陆拨打 120）。
