日期：2026-09-13。范围：执行已确认方案中不依赖模型选型的工作。保留原有四页视觉结构，模型选择、真实接入和专业审核继续后置。

## 已实现

| 模块 | 本轮结果 |
| --- | --- |
| 本机记录 | IndexedDB 事务保存档案、收藏、方案、测评和草稿；旧版迁移幂等，固定体质结果不迁入 |
| 方案 | 新方案独立 ID；增重示例含三餐和加餐；继续调整带入原方案；修订冲突与删除后更新被拒绝 |
| 新测评 | 32 道候选题配置、八类选项、返回修改、未答检查、草稿恢复、自愿保存、多份记录及删除 |
| 计分 | 独立描述性计算；非数值答案不计零；无体质分类；不接受伪造的试测 Agent 资格 |
| 咨询接口 | 同站点 POST /api/agent；服务端预设场景；受限上下文、内容引用、用户选择附带饮食偏好 |
| 交互状态 | 等待、取消、超时／错误重试；关闭／新对话令旧回复失效；保存等待存储事务完成 |
| 健康规则 | 已知紧急示例直接求助、无方案和追问；特殊背景保守处理；一般知识入口保留 |
| 中药限制 | 12 组初始禁配规则、已知组内展开及现用成分合并检查；未知不作为安全通过 |

产品范围没有缩减为三餐或茶饮专用工具。当前接口是可运行的测试替身，预设场景数量不代表真实 Agent 的最终知识范围。

## 自动化验证

`npm test` 使用 Node 内置测试运行器，目前 46 项通过；`npm run build` 构建通过；9 份文档、58 个本地链接检查通过。`fake-indexeddb` 用于事务及跨连接竞争测试，真实浏览器另行验证 IndexedDB 与界面集成。

覆盖计分 0/4 极值、混合均值、三类非数值答案、缺项、非法及重复答案、版本拒绝；记录迁移、刷新读取、并发修订、删除后更新、多个结果和清除；紧急回复不变量、否定／历史例句、已知风险上下文、特殊人群一般科普、禁配组合、未知身份、极端饮食目标、实际方案替换、起居时间记录、引用合法性，以及 HTTP 方法、来源、格式、请求大小和不缓存。

这些测试证明的是程序在所列输入下的行为，不验证医学有效性，也不等于健康规则全部 HC／HBQ 对话验收已经完成。

## 浏览器验证

使用同一个 Ego 浏览器测试空间与本地同站点预览，填写虚构数据。已验证：档案保存与刷新；完整增重示例的保存、鱼换豆腐及同一记录修订到 2；32 题作答、非数值选择、退出恢复到第 2 题、提交及自愿保存后刷新；起居示例保存；清除后数据库五个业务存储均为 0、旧版键与聊天为空；取消请求后忽略晚到回复；紧急提示不出现方案或食谱按钮。手机 390 × 844 视口中首页无横向溢出，起居切换与咨询输入区可用；茶饮收藏刷新保留，手机咨询框宽度为 390、输入区底部为 818，位于 844 高度的视口内。部分滚动容器内的自动指针点击受到遮挡，改用同一浏览器的居中滚动及 DOM 操作核对功能。

## 尚未完成的正式 MVP 条件

- 真实模型供应商、适配器、费用、凭据和数据处理条款；RAG 与外部 MCP 接入。
- 新问卷的专业审阅、适用性、测量验证和正式体质判定规则；现在只交付试测流程与描述性记录。
- 内容专业审核、完整原料身份和炮制映射、现行药典核对、复方成分、药物相互作用及特殊人群依据。
- 完整语义识别、跨轮风险事实管理、专业场景审核和持续误答监测。当前关键词分流不具备可靠分诊能力。
- 真正的个性化食养／草药方案和任意餐次自由替换；本轮开放明确标记的三餐预设、鱼换豆腐，以及起居示例中用户自选准备时间的记录。
- 生产级分布式限流和访问控制检查。当前依赖原有站点私有访问边界，接口内只有同源检查、体积限制和短时实例内限流，不能当作全面安全防护。

## 技术与运行说明

运行源在 `src/`、`content/` 和 `rules/`；`dist/client`、`dist/server` 为构建输出。没有采集姓名作为咨询上下文，也不自动发送测评答案。服务端不保存产品健康记录或打印问题正文；平台层的日志政策仍需正式核对。

当前方案接口的 `requestedChange` 意图直接来自 `message`；没有批准任何 `assessmentSummary` 进入模型。`safetyContext` 仅保留本会话已出现的保守标记，不能降低服务端依据消息判断出的限制。

本轮构建使用项目自己的 `npm run build`：会话中 Sites 插件辅助脚本所在目录变为不可用，已经检查所列路径及技能根目录；现有原生 Sites 发布工具仍可调用。自定义 Worker 的发布归档仅包含构建产物和站点清单，不包含健康记录、依赖目录或密钥。
