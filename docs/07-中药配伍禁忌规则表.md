## 1. 首版采用的约束

十八反、十九畏明确纳入中药及食药物质推荐的前后校验。命中时不生成、展示或保存该具体推荐；用户要求“少量试试”“炮制后用”“间隔服用”或称自行承担风险，都不能改变阻断结果。

本表记录传统配伍禁忌，并将其作为本产品的保守限制。不声称所有组合在任何情形下都具有相同的已证实毒性，也不采用临床特殊配伍作为养生产品放行的理由。提及医生已开具的处方时，只说明需要由开方医生或药师核对，不替用户作停药、换药或改方决定。

十八反、十九畏不是全部中药安全规则。即使没有命中，仍须核对原料用途、身份、部位、制法、过敏、药物相互作用、孕哺与年龄、疾病限制和内容审核状态。药用专用、毒性或身份不明的原料不进入首版供用户自行食用的推荐目录；历史名称出现在下表不代表本产品提供该原料。

## 3. 名称与成分核对

每个规则记录：稳定 ID、原料规范 ID 或成员集合、原始名称、来源版本与位置、适用部位及制品形式、已审核映射、阻断说明、审核状态。未完成名称核对时返回 `unknown`，不能返回“安全”。

| 情形 | 处理方式 |
| --- | --- |
| 同一名称的繁简体或明确错别字 | 通过人工核对的映射识别，保留用户原输入；有歧义时澄清 |
| 白及／白芨等常用写法 | 建立可追溯别名记录后使用，不让模型临时创造等价关系 |
| 官桂、石脂、牙硝、牵牛等历史或概括名称 | 逐项核对与现用原料的对应；未明确的名称不作为具体推荐放行依据 |
| 生品、炮制品、提取物或不同部位 | 保存各自身份和来源；不因“制”“炙”等字样消失就漏查，也不默认炮制解除禁忌 |
| 中成药、复方饮品或已有茶方 | 按准确产品与已核对的成分资料检查；仅有商品名、图片识别不清或配方不完整时视为资料不足 |
| 食药物质或普通食物名称与药名相似 | 不靠单字或子串判断配伍，先核对身份；同源或同名不自动等价 |

首版核对集合包括候选饮品／方案中的全部原料、用户说明正在使用的中药及可核对中成药成分，以及同一安排中的其他相关饮品。不能只检查一张卡片内部，遗漏跨茶饮、跨餐食或与现有用药的组合。中成药中包含相反药味的联用问题也需要关注。[S18 药监部门用药安全说明](https://mpa.xinjiang.gov.cn/xjyjj/yyaq/202312/24cdf9e5b01a4c608ef79592a9c4f4bb.shtml)

不将查询词、引用内容或“不要加入某原料”机械并入实际服用集合；也不因用户删掉一个当前问题中的药名而忽略已知在用成分。相关上下文未知、矛盾或过期时，限制具体推荐并核实。

## 4. 输出与例外

命中配伍限制时，可解释“这组原料涉及已记录的配伍禁忌，本产品不提供组合食用方案，请由医生或药师核对”。不补充减量、比例、炮制、替换药材或时间间隔等绕过方法，也不自行调整现有处方。

未命中但资料不足时，说清尚未核实的项目，不展示“配伍安全”“无禁忌”或“放心长期喝”。一般科普可说明传统禁忌的背景，但不能把学术讨论或古方例外变成用户可执行的合用指引。

推荐前和生成后都检查，覆盖正文、引用解释、原料表、卡片及待保存方案。任何一处仍在建议被阻断的组合，整体具体推荐都不能交付；不能删掉卡片后留下正文配方。
