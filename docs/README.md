# 知养文档目录

给面试、投资人附件和仓库内查阅。现行产品是饮食记录助手：记下吃了什么，看今天大约吃了多少，再从自己的食谱库里选下一餐。个人项目，作者 linden。

面试时建议先看产品一页纸，再看功能需求文档。技术追问看 Agent 需求规格和部署说明。
