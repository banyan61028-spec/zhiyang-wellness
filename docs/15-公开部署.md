# 公开部署

给朋友一个网址，再单独把邀请码发给他们。没有账号。饮食记录仍只留在各自的浏览器里。邀请码只决定能不能打开这个服务。

## 环境变量

公开部署时在平台的环境变量里填写，不要写进仓库，也不要提交 `.env`。

```
INVITE_CODES=friend-2026-east,friend-2026-west
INVITE_SECRET=请换成至少32位的随机字符串
DASHSCOPE_API_KEY=你的密钥
DASHSCOPE_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
DASHSCOPE_VISION_MODEL=qwen3-vl-flash
DASHSCOPE_TEXT_MODEL=qwen-plus
BOOHEE_API_KEY=你的密钥
HOST=0.0.0.0
```

- `INVITE_CODES`：接受的邀请码，用逗号或空格分开，前后空格会去掉。不设置或留空时不拦截，本机 `npm run dev` 不用配也能打开。
- `INVITE_SECRET`：邀请码开启时必填。服务用它签发 cookie，cookie 里没有邀请码原文。请用一长串随机字符，不要和邀请码相同。
- `DASHSCOPE_API_KEY`：识别食物和写建议。不设置时走测试替身。`DASHSCOPE_BASE_URL`、`DASHSCOPE_VISION_MODEL`、`DASHSCOPE_TEXT_MODEL` 按实际平台选填。
- `BOOHEE_API_KEY`：本地食物表算不了时才查询薄荷。可以不填。
- `HOST`：公开部署用 `0.0.0.0`。`npm start` 在环境变量和 `.env` 都没写 `HOST` 时默认就是这个。`npm run dev` 仍默认只听 `127.0.0.1`。
- `PORT`：由 Railway、Render、Fly 注入。没设置时是 8765。

## 启动

```sh
npm ci
npm start
```

`npm start` 发现还没有 `dist` 时会先构建，然后监听 `0.0.0.0` 和 `PORT`。

Docker 镜像同样适用于 Railway 和 Render：

```sh
docker build -t zhiyang .
docker run --env-file .env -p 8765:8765 zhiyang
```

镜像里执行的是 `npm ci`、`npm run build`、`npm start`。平台分配的 `PORT` 会覆盖默认端口。

HTTPS 由平台终结时，请保留 `X-Forwarded-Proto: https`（Railway 和 Render 会带上）。这样浏览器收到的 cookie 才带 `Secure`。cookie 名是 `zhiyang_invite`，`HttpOnly`、`SameSite=Lax`，大约 90 天。直接用 http 打开本机时不带 `Secure`，否则浏览器不会保存，邀请码对完也无法进入。
