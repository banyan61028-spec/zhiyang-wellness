## 1. 内容如何使用

这一批资料用于把首页、内容详情和将来的 Agent 推荐具体化。包括知识摘要、餐食搭配草稿、茶饮候选、起居内容、专题和文章；不要求现在建成百科或向量数据库。

| 层次 | 当前可做 | 进入真实服务前还需要什么 |
| --- | --- | --- |
| 一般知识摘要 | 审阅、核对表述与来源、开发引用显示 | 核对正文、适用范围、时间与审核状态 |
| 普通食材搭配 | 演示餐食卡片、替换关系与准备方式 | 逐条核对过敏原、准备方法、适用说明；个性化时另核对用户条件 |
| 食养茶饮候选 | 展示内容字段设计和待核对材料 | 完整原料身份、准备与用量依据、相互作用及人群限制、专业内容复核 |

有公开来源不等于已经审核。有一般原则来源不等于有具体配方依据。以传统观点介绍的内容，明确保留“传统食养中的说法”等语境，不转成保证有效的现代医学结论。

本稿的通用内容元数据为：`contentVersion = 0.1.0-draft`、`reviewStatus = pending`、`reviewer = null`、`reviewedAt = null`、`recommendationEnabled = false`。候选内容不能因为已有 ID 就进入真实推荐白名单。

明确紧急情况时不推荐本稿任何餐食、茶饮或起居方案；特殊人群与特殊情况缺少必要支持时不生成个人方案。涉及中药或食药物质的条目须核对十八反、十九畏及其他限制，并检查整份安排和已知在用成分。审核完成也不等于适合每一位用户。

| P02 | 专题：想喝一杯中式食养饮品 | 解释原料身份、用药与过敏信息为什么相关，展示完成审核后的饮品 | K02、K03；当前 T01、T02 仍待核对 |
| P03 | 专题：觉得“湿气重” | 先邀请描述实际感受和发生变化，再区分知识解释与具体生活问题 | H03；不展示自动祛湿消肿方 |
| P04 | 专题：排便不顺 | 进入 K06，询问持续时间及相关生活条件，显示适当的专业帮助说明 | S11；成人资料不直接迁移到婴幼儿 |
| P05 | 专题：嗓子不舒服 | 进入 K07，从能否正常吞咽、发生多久等必要信息开始 | S12；不把茶当治疗 |
| P06 | 专题：作息不规律 | 从 R01、R02 选择能做的调整，持续困扰时说明求助方向 | S06；不是只服务睡眠问题的定位 |

以上六个专题是内容编排草稿，整合了已有体重、茶饮、排便、咽喉、作息等演示方向，并补出用户明确提出的“湿气重”入口。实际替换 Demo 专题前记录 ID 对应，保持收藏和历史入口可识别。它们不限定用户可以问什么。

三篇短文章正文草稿：

### A01：一份三餐安排，先要适合你的生活

先说清自己通常在哪里吃饭、愿意花多少时间，以及不吃或不能吃的食物，再看搭配会更容易落到生活里。可以围绕主食、蔬菜和蛋白质食物组织一餐，结合全天饮食调整种类。这是一般搭配思路，并不是为个人计算过热量的减重或增重计划。[膳食原则来源 S05](https://www.nhc.gov.cn/xcs/c100122/202206/d4941efa5d6544e2abac68127c3238c0.shtml)

在知养中，你将可以把不方便准备的一餐换掉，再保存自己的安排。替换时仍要核对新食物的原料；两份看起来相似的餐食，不自动意味着营养等量。

### A02：有“茶”字，也要看清具体是什么

了解一杯食养饮品，可以先看原料名称、使用部位和准备方法。“中药”“食药物质”和普通饮品是需要分别核对的内容，不能仅凭名字判断是否适合自行长期饮用。[原料管理依据 S07](https://www.nhc.gov.cn/sps/c100088/202111/a0f07a6f1d4f4607add51e5a9de73abe.shtml)

正在用药时，准确的药名有助于核对可能的相互作用。知养后续会将经过审核的饮品与相应限制一起展示；资料不足时，先说明尚未查清的内容。[相互作用参考 S09](https://www.nccih.nih.gov/health/tips/tips-how-herbs-can-interact-with-medicines)

### A03：做完体质测评，结果能说明什么

中医体质有九种基本类型，具体辨识需要相应问题和计分方法。产品里的问卷还必须说明采用哪个版本、适用范围以及验证状态。[标准背景 S01](https://www.samr.gov.cn/xw/sj/art/2026/art_bbc0d96fbbb741a2a66d2f4f7a44fd82.html)

知养正在重新设计测评题目。目前候选题只用于试测与整理自我感受，不能当作疾病判断，也不会据此自动开茶方。你可以先浏览体质知识，或直接提出生活中的健康问题；咨询不以完成测评为前提。

九种体质的介绍继续沿用 S01 确认的名称：平和、气虚、阳虚、阴虚、痰湿、湿热、血瘀、气郁、特禀。相关介绍正文仍需按当前资料核对，不把“题目候选表”直接改写成“出现这些表现就属于该体质”。

## 7. 每条内容补齐与审核的顺序

1. 助手取得完整资料、核对适用对象和具体支持位置，注明哪些是原文事实、哪些是产品编写的搭配。
2. 助手补齐条目原料、做法、限制与引用，消除缺失或冲突，提交具体内容供专业复核；不让用户先写完整知识库。
3. 相应专业人员按内容范围复核；记录姓名或内部标识、日期、通过的具体版本和待修改项。不能由助手虚构审核人或冒称已审核。
4. 经审核的条目才可转为可推荐内容；改变配方、原料、用量或适用说明时形成新版本并重新核对。
5. 接模型后验证它是否只引用实际提供的来源、是否遵守条目限制；此项后置，当前不计为通过。

没有合适茶饮时不阻断整个咨询；没有某一疾病专题时也不拒收问题。开发阶段可以使用明确标为演示的内容测试状态和界面，不以资料数量替代内容可靠性。
